Entry for the make.fun competition
`u-mfnakmal-the-comment-above-the-code-35e38026` ($2, 1st place $0.63).

`main.ts` writes one line — at most 200 characters — to `/output/entry.txt`:
the comment a developer left above fragile production code, funny and
painfully honest at once. It validates the line against the competition
gate (1–200 characters, not only whitespace, a single line) and verifies
the written file byte-for-byte, so the output is deterministic across runs.

Run it with Node 22.18 or later:

```
node main.ts
```
